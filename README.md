# Sistema de notebooks
### Um sistema pratico para organizar a retirada e devolução de notebooks
## Objetivo:
### Nosso sistema resolve o problema na dificuldade de gerenciamento e a falta de praticidade ao retirar e devolver notebooks, por que utilizamos um sistema que envolve um scaner que lerá código de barras dos notebooks e do crachá de professores e monitores.
