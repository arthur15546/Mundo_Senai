# Sistema de notebooks
### Um sistema prático para organizar a retirada e devolução de notebooks
## Objetivo:
### Nosso sistema resolve o problema que é a dificuldade de gerenciamento e a falta de praticidade ao retirar e devolver notebooks. Para solucionar utilizamos um sistema que envolve um scanner no qual lê um código de barras que estará colado em cada notebook e no crachá de professores e monitores. Cada código de barras será diferente, dando uma identidade no site para cada usuário e item. Contudo, o principal objetivo é facilitar a retirada de notebooks realizada pelos professores e monitores, diminuindo o tempo perdido de aula para tal ação.
## O que utilizamos:
### Programação em python, banco de dados, scanner.
